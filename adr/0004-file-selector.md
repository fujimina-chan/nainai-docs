# ADR-0004: 入力ファイル選択に file_selector を採用

## ステータス

承認済（Accepted）

## コンテキスト

MVP では、ユーザーが端末内の音声・動画ファイルを OS 標準のファイル選択 UI 経由で選び、アプリがその参照を利用する必要がある。入力ファイル選択の実装技術を決定する。

将来は音声・動画・歌詞・字幕・説明などの **出力先** を個別指定する要件がある。OS ごとに保存先選択の制約が異なるため、入力と出力を同一技術に固定すると拡張を阻害しうる。

## 検討した選択肢

- `file_selector`（flutter.dev）を入力ファイル選択に採用する
- 他のファイルピッカー系パッケージ、または各 OS ネイティブ API を直接利用する

## 決定

MVP の **入力ファイル選択** に次を採用する。

| 項目 | 内容 |
|------|------|
| パッケージ | `file_selector` |
| バージョン | `1.1.0` |
| publisher | `flutter.dev` |

用途は「端末内に保存されている音声・動画ファイルの選択」に限定する。

本決定は、**将来の出力先選択にも `file_selector` を採用する** という意味ではない。

概念上、次を分離する（クラス名は未確定）。

- MediaSelection（入力ファイル選択）… 本 ADR の対象
- OutputLocationSelection（出力先選択）… 技術未選定

## 結果

- Flutter 公式 publisher のパッケージで、OS 標準 UI による単一ファイル選択が可能になる
- Windows / Android / iOS（MVP）および将来の Web / macOS / Linux に対応可能な構成を取れる
- 出力先選択は別責務として残し、将来の個別出力先指定を阻害しない
- 対応メディア形式の一覧は本 ADR の対象外（未確定）
