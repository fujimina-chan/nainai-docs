# ADR-0001: Flutter 採用

## ステータス

承認済（Accepted）

## コンテキスト

nainai は Windows / Android / iOS を初期対象とし、将来 Web / macOS / Linux への拡張も予定しているクライアントアプリケーションである。複数プラットフォームを効率よく開発・保守するため、クライアント実装フレームワークを決定する必要があった。

## 検討した選択肢

- Flutter によるクロスプラットフォーム開発
- 各 OS 向けのネイティブ個別実装

## 決定

クライアントアプリケーションは **Flutter** を採用する。

| 項目 | 内容 |
|------|------|
| Flutter project name | `nainai` |
| 言語 | Dart（Flutter SDK に同梱されるものを使用） |
| コードベース | 可能な限り共通の Flutter コードベースを使用 |
| プラットフォーム固有処理 | 必要に応じて各 OS 側へ分離 |

## 結果

- Windows / Android / iOS を共通コードベースで開発できる
- 将来の Web / macOS / Linux 拡張を同じ技術スタックで進めやすい
- プラットフォーム固有処理のみ個別実装できる
- ファイル選択・メディア再生などに使う具体的なライブラリは、本 ADR の対象外（未確定）
