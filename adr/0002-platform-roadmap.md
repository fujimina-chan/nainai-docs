# ADR-0002: プラットフォームロードマップ

## ステータス

承認済（Accepted）

## コンテキスト

nainai の初期リリース範囲と、将来のプラットフォーム拡張方針を明確にする必要があった。過去の文書では「Web 非対応」と解釈されうる表現があり、恒久的に Web を除外する決定ではないことを正本で明確にする。

## 検討した選択肢

- 初期から全 Flutter 対応プラットフォームを対象にする
- 初期は Windows / Android / iOS に絞り、Web / macOS / Linux は将来対応とする

## 決定

プラットフォームロードマップは次のとおりとする。

| フェーズ | プラットフォーム |
|----------|------------------|
| 初期（MVP） | Windows / Android / iOS |
| 将来対応予定 | Web / macOS / Linux |

本決定は **「Web 非対応」ではない**。

- Web / macOS / Linux は初期 MVP の対象外である
- これらは将来対応予定であり、恒久的な非対応ではない

## 結果

- MVP の実装・検証範囲が Windows / Android / iOS に明確化される
- 将来の Web / macOS / Linux 対応を設計上の前提として残せる
- Flutter 共通コードベース方針（[ADR-0001](0001-use-flutter.md)）と整合する
