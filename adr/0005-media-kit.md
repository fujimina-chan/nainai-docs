# ADR-0005: 音声・動画再生に media_kit を採用

## ステータス

承認済（Accepted）

## コンテキスト

MVP では、選択したローカル音声・動画ファイルをアプリ内で再生し、再生 / 一時停止 / 停止 / シーク / 音量 / 再生位置表示、および動画の映像表示を行う必要がある。音声と動画を別系統にすると実装・保守コストが増えるため、共通の再生基盤を選定する。

## 検討した選択肢

- `media_kit`（video 用構成）を共通再生基盤とする
- 音声用・動画用に別パッケージを組み合わせる構成

## 決定

MVP の音声・動画再生基盤として次を採用する。

| パッケージ | バージョン |
|------------|------------|
| `media_kit` | `1.2.6` |
| `media_kit_video` | `2.0.1` |
| `media_kit_libs_video` | `1.0.7` |

構成方針:

- 音声・動画の両方を扱うため video 用構成を使用する
- `media_kit_libs_audio` と `media_kit_libs_video` を同時使用しない

## 結果

- 音声・動画を同じ再生基盤で扱える
- Windows / Android / iOS（MVP）および将来の Web / macOS / Linux に対応可能な構成を取れる
- 再生、一時停止、シーク、音量、再生位置、動画描画など MVP 要件に適合する
- 製品リリース前に、ネイティブ依存・コーデック等を含む **推移依存ライセンス監査を必須** とする（本 ADR では監査未実施）
- 対応メディア形式の一覧、FFmpeg 採用有無は本 ADR の対象外（未確定）
